JYM Super VPN - Android Studio project skeleton
------------------------------------------------
IMPORTANT:
- This template provides a legal VPN client skeleton for Android (Kotlin).
- I WILL NOT help create or include any code that attempts to access carrier networks
  (e.g., "free Airtel servers") without authorization. Bypassing billing or carrier
  restrictions is illegal and disallowed.
- To build a functional VPN client, integrate a proven open-source VPN backend
  such as WireGuard or OpenVPN and follow the backend's installation instructions.

What is included:
- Android Studio project skeleton (Gradle)
- Minimal MainActivity with UI to import a VPN config and start/stop the VPN (placeholder)
- Notes in code where to integrate WireGuard/OpenVPN libraries

How to use:
1. Open this folder in Android Studio.
2. Add the VPN backend library you prefer (WireGuard or OpenVPN) as a dependency and follow
   that project's setup guide.
3. Implement the VPN start/stop logic where marked in MainActivity.kt.

Legal reminder:
Use this app only to connect to VPN servers you are authorized to use.
